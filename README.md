# G2Ray - Xray VLESS on GitHub Codespaces

این پروژه برای ایجاد سریع و آسان یک سرور پروکسی VLESS بر روی GitHub Codespaces طراحی شده است.

## ویژگی‌های جدید و بهبودها
- **تولید UUID پویا**: برای افزایش امنیت، به جای استفاده از یک UUID ثابت، در هر بار راه‌اندازی یا بیلد، یک UUID تصادفی تولید می‌شود.
- **ارسال لینک به تلگرام**: شما می‌توانید لینک VLESS تولید شده را به صورت خودکار به ربات یا کانال تلگرام خود ارسال کنید.
- **بهینه‌سازی مصرف API گیت‌هاب**: اسکریپت `watch.sh` بهینه‌سازی شده تا فقط در صورت لزوم درخواست تغییر وضعیت پورت را ارسال کند و از لیمیت شدن اکانت شما جلوگیری شود.

## نحوه استفاده
۱. این ریپازیتوری را فورک (Fork) کنید یا از آن به عنوان قالب استفاده کنید.
۲. روی گزینه **Code** کلیک کرده و تب **Codespaces** را انتخاب کنید.
۳. یک Codespace جدید بسازید.
۴. منتظر بمانید تا کانتینر ساخته شود و ترمینال بالا بیاید. لینک VLESS به طور خودکار در ترمینال به شما نمایش داده می‌شود.

## اتصال به ربات تلگرام
برای اینکه به محض ایجاد و راه‌اندازی محیط، لینک پروکسی برای شما در تلگرام ارسال شود، مراحل زیر را طی کنید:

۱. در ریپازیتوری خود به مسیر `Settings` -> `Secrets and variables` -> `Actions` (برای تنظیمات اکشن) و `Codespaces` بروید.
۲. متغیرهای زیر را به عنوان **Repository secrets** هم در بخش Codespaces و هم Actions اضافه کنید:
   - `TG_BOT_TOKEN`: توکن ربات تلگرام شما (از BotFather دریافت کنید).
   - `TG_CHAT_ID`: شناسه چت یا کانال شما.
   - `GH_PAT_TOKEN`: یک توکن شخصی گیت‌هاب (Personal Access Token) با دسترسی `codespace`. این توکن برای روشن نگه داشتن خودکار سرور نیاز است.

## سیستم ضد خاموشی و ساخت خودکار (Keep-Alive)
گیت‌هاب کانتینرها را پس از مدتی خاموش می‌کند. اما این پروژه مجهز به یک **GitHub Action** است که به صورت خودکار:
- هر ۳ ساعت وضعیت سرور شما را بررسی می‌کند.
- اگر سرور خاموش شده باشد، آن را روشن می‌کند.
- اگر روشن باشد، برای نوسازی اتصال آن را ری‌استارت می‌کند.
- **یک لینک VLESS با UUID کاملاً جدید** می‌سازد و بدون دخالت شما، مستقیم به تلگرام‌تان ارسال می‌کند!

---
> **نکته:** GitHub Codespaces پس از مدت زمان مشخصی عدم فعالیت خاموش می‌شود. برای پایداری بهتر، می‌توانید از ابزارهایی برای پینگ کردن یا متصل نگه داشتن کلاینت استفاده کنید.
